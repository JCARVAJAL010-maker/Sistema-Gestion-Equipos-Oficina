# Sistema de Gestión de Equipos de Oficina

Proyecto final de Programación II.

## Descripción
Sistema para gestionar computadoras, impresoras y otros equipos de oficina, así como sus asignaciones a empleados y mantenimientos.

## Entidades principales
- Equipo
- Empleado
- Asignacion
- Mantenimiento

## Tecnología
- C#
- ASP.NET Core
- Base de datos relacional
